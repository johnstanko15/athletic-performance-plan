GITHUB UPDATE
1. Open the existing GitHub repository.
2. Choose Add file > Upload files.
3. Upload all seven files listed above.
4. Commit the changes.
5. Wait for GitHub Pages to redeploy.

IPHONE ICON UPDATE
1. Open the site in Safari after deployment and refresh.
2. Delete the old Home Screen shortcut.
3. In Safari, choose Share > Add to Home Screen.
4. The new silhouette icon should appear.

LOCAL DATA
Workout logs, PRs, bodyweight and photos are stored locally on the device/browser.
Progress photos are not uploaded to GitHub.
