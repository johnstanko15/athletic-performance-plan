ATHLETIC PERFORMANCE TRACKER

WHAT THIS IS
A phone-friendly Progressive Web App containing the four-week workout program.
It includes day/week navigation, movement checkboxes, weight/repetition/notes fields,
saved progress using your browser's local storage, and a YouTube demo-search link for each movement.

HOW TO RUN LOCALLY
1. Unzip the folder.
2. Open a terminal in the folder.
3. Run: python3 -m http.server 8000
4. Open http://localhost:8000

HOW TO PUT IT ON AN IPHONE
1. Upload the folder to a static host such as Vercel, Netlify, GitHub Pages, or Cloudflare Pages.
2. Open the published URL in Safari.
3. Tap Share > Add to Home Screen.

IMPORTANT
The current demo buttons open targeted YouTube searches, not individually curated videos.
This avoids dead or misleading links and can be upgraded later to exact videos.
Data is stored only on the device/browser where you use the app.
